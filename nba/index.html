Lets this page read the private propedge repo, so it always runs the current engine. It can't change anything.
Make a new token Open GitHub's token page ↗
  1. Sign in to GitHub if it asks. The page opens with the name, a one-year expiry and Contents: Read-only already filled in.
  2. Repository access: tap Only select repositories and pick propedge. That's the one thing to choose.
  3. Permissions should list just Contents and Metadata, both Read-only.
  4. Tap Generate token, then copy the token (it starts with github_pat_). GitHub shows it only once: save it in 1Password too.
  5. Come back to this page and paste it in the GitHub token box.
